五四共青团刷题 · PWA 安装与部署说明

【这是什么】
这是一个可安装到手机主屏幕的 PWA。安装后点开是独立窗口，第一次联网加载后，之后可以离线刷题。

【部署（任选一个 HTTPS 静态托管）】
1. Cloudflare Pages：新建项目 → Direct Upload → 上传本压缩包解压后的全部文件 → 获得 https 链接。
2. GitHub Pages：新建仓库 → 上传解压后的全部文件 → Settings → Pages → 选择分支 → 获得 https 链接。
3. Netlify Drop：把解压后的文件夹拖进去 → 获得 https 链接。
4. Vercel：导入静态项目 → 获得 https 链接。

注意：必须用 HTTPS 打开，file:// 本地文件不能安装 PWA。
不要把文件放进需要登录的网盘直链，浏览器需要能直接访问 index.html。

【安卓手机安装】
用 Chrome 打开部署后的链接 → 右上角菜单 → “安装应用”或“添加到主屏幕”。
如果页面右下角出现“安装到手机”按钮，也可以直接点它。

【iPhone 安装】
用 Safari 打开链接 → 底部“分享” → “添加到主屏幕”。

【离线说明】
第一次打开需要联网，Service Worker 会缓存页面、图标和题库。
之后断网也能打开；如果更新了题库，联网重新打开一次即可拿到新版。

【数据说明】
练习记录保存在手机浏览器的本地存储中，不上传服务器。
换浏览器、清理站点数据或卸载 PWA 后，记录会丢失。
